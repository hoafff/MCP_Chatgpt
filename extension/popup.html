Safe Manual-Send Mode
Reads local data into the composer only. It does not inspect ChatGPT replies and never presses Send for you.

Type @local plus a Windows path, then press Enter once.

The extension will replace the composer with your request + local data and stop. Review it, remove anything sensitive, then press Send yourself.

Read-only local access: file info, file read, directory list.
